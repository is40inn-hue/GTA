# ЕГЭ по истории GTA — RC4.2, предфинальная

17 ноября 2026 · один полный ZIP для публикации и локального теста.

## Главное — часть C готовится с обложки

После первого отображения обложки начинается фоновая загрузка города, моделей и движка. Затем тот же настоящий native runtime тихо готовит начальную сцену. До «Начать» экзаменационная попытка не создаётся. При переходе через A/B город сохраняется; готовая C открывается без повторного запуска и без прежнего трёхсекундного отсчёта.

На слабой сети или при экономии ресурсов подготовка может не успеть: тогда текущая загрузка продолжается на экране ожидания с реальным прогрессом. Гарантии нулевой задержки для любого устройства нет.

## Изменения

- Розовая шапка в стиле бланка ЕГЭ: клетки, метки сканирования, штрихкод; сохранены кремовый, синий, magenta и небольшие Vice-акценты.
- C1: припаркованный Maverick вместо автомобиля. Два мирных прохожих реагируют на первое подтверждённое попадание, у третьего остаётся короткое нападение.
- РПГ лежит на два метра впереди старта, рампа сбоку. Одна красная метка указывает текущую цель, подсказка обновляется по настоящему native состоянию. Вертолёт в воздухе остаётся финалом.
- На обложке — «Практика C отдельно». Первый запуск имеет отдельный экран подготовки, запуска и площадки. Проценты показывают реальные данные.
- Большие кнопки практики, поднятая зона управления, учёт безопасных краёв экрана; пауза доступна вверху.
- Оценка каждой части — 1–5 звёзд по доле баллов. A/B показываются на промежуточном итоге, C — после комиссии. При самостоятельной практике C её итог появляется после третьей сцены.
- Итоговая PNG-картинка 1080×1920 сохраняет имя, аватар, баллы и настоящий кадр C, если движок успел его снять; добавлены звёзды A/B/C. Взрыв не рисуется искусственно: при его отсутствии используется честный доступный кадр/резервный фон.

Вопросы A/B сохранены. Экзамен: 12 заданий, A 24 + B 40 + C 36 = 100; зачёт от 60.

## Публикация на Netlify

Распакуй весь ZIP. На Netlify Drop перетащи **папку, внутри которой непосредственно лежит index.html**. Рядом с ним должны быть app.js, assets/ и native-vc/. Не выбирай папку уровнем выше. Build command не нужен.

У прошлой публикации файлы оказались внутри /dist/: главная возвращала 404. Этот архив имеет index.html прямо в корне. Старые ссылки /dist/* перенаправляются на корневые пути при публикации содержимого ZIP.

## Локальный тест

Распакуй архив и запусти START-MAC.command, START-WINDOWS.cmd или START-LINUX.sh. Нужен установленный Node.js 16+ либо Python 3.7+. Launcher напечатает адрес и откроет браузер; держи его окно открытым. Если порт 4173 занят, выбирается свободный порт. Подробности — START-HERE.txt.

Не открывай index.html как файл. Адрес 127.0.0.1 относится к компьютеру, на котором запущен launcher. Для C нужен WebGL 2.

## Что проверено

263 автоматические проверки проходят. Сверены 1044 native файла, их размеры/хэши и SCM. В браузере проверены A до 24/24 и 5 звёзд, отдельная C, оформление ожидания и мобильная геометрия.

Это **предфинальная**: облачный браузер не предоставляет WebGL 2, поэтому реальное native прохождение и скорость на телефоне ещё не проверены. Для финального приёма: открыть архив на телефоне/в Telegram с WebGL 2, пройти A/B обычным темпом и проверить появление C, затем pickup → цели → вертолёт и итоговую картинку.
