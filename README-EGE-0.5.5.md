# ЕГЭ GTA 0.5.5 · Живые кадры в теории

Патч содержит обновления 0.5.2–0.5.5. Распаковать рядом с index.html
полной сборки 0.5.1–0.5.4 и подтвердить замену файлов. В Render не опубликован.

* A2: радиовертолёт поднимается по кнопке; можно тянуть его пальцем или мышью,
  либо двигать стрелками. Это интерактивная 2D-композиция подлинного кадра
  Vice City, а не запущенный движок: оригинальной модели маленького
  вертолёта в поставке нет. Если виджет не загрузится, остаётся обычный кадр.
* B3: кнопка запускает короткую учебную запись патруля. Карта и рамка взяты
  из игры; их рисует тот же радар, что используется в C. Маршрут и звёзды —
  постановочные; их можно посмотреть повторно.

Виджеты необязательны, не показывают правильный ответ, не меняют баллы или
сохранение и не запускают дополнительную копию движка. Существующие вопросы
и часть C сохранены. Системная настройка уменьшения движения учитывается.
Локальные проверки поведения пройдены, реальный iPhone не проверялся.
