# ЕГЭ GTA 0.5.3 · Допуск к GTA VI

Патч поверх полного билда 0.5.1 (коммит 465c09b в GitHub) или 0.5.2. Для
установки распаковать ZIP в корень существующей сборки рядом с index.html,
подтвердить замену файлов. Архив не запускается отдельно. Публичного
деплоя этот патч не выполняет.

Один и тот же номер билета в классе Vice City, первом вопросе, переходах между
частями, на проверке комиссии и в итоговой карточке. Уличные испытания остаются
теми же тремя заданиями, теперь с общей нумерацией в интерфейсе. Новых экранов,
шагов и изменений базы вопросов, баллов или логики практики нет.

Красная печать из присланного оригинала рисуется в готовой карточке, поэтому
сохраняется и в PNG для сториз. Только официальный результат от 60/100.
Ниже 60 и в тренировке печати нет. Если фото печати не загрузится, сохраняется
разборчивый текстовый вердикт. Успешный результат не изображается заранее.

Проверено автоматически: прохождение этапов, пропуск вступления и продолжение
сохранённого экзамена; граница 59/60, отказ при 46, отсутствие печати в
тренировке, экспорт карточки и резервный текст. Полный прогон на физическом
iPhone в Telegram, включая настоящий 3D-класс и уличную практику, не выполнялся.

Ручная проверка: начать новый экзамен, дождаться класса или нажать
«Пропустить», пройти A → B → C, сравнить номер билета на проверке и карточке.
Проверить успешный результат и пересдачу. Для локального запуска использовать
встроенный START-MAC.command / START-WINDOWS.cmd / START-LINUX.sh, не file://.
