# ЕГЭ по истории GTA — RC4

16 ноября 2026 · `gta-ege-rc4-20261116-dist.zip` · база: RC3 от 15 ноября 2026.

## Что изменилось

- Сокращены повторяющиеся подписи, инструкции и кнопки на главной, вопросах, переходах и результате. Звук, пауза и восстановление после ошибки сохранены. Подробный разбор ответов теперь свёрнут.
- Во время работы комиссии автоматически готовится карточка **1080×1920**. После проверки сразу показана эта картинка: результат, имя и доступный аватар, баллы A/B/C и настоящий кадр практики, если его удалось получить. Отдельного шага создания картинки больше нет.
- Включён захват кадра из отрисованной части C. Предпочтение отдаётся удачному кадру уничтожения финального вертолёта; число проб и размер изображения ограничены. Захват не меняет управление и начисление баллов. Если взрыв не попал в кадр, используется доступный игровой кадр; если снимок недоступен — типографическая карточка без выдуманного взрыва. Без доступного аватара показывается инициал.
- Сохранение и системная отправка используют ту же готовую PNG, что видна на экране. Учтены поздняя загрузка аватара, смена попытки и ошибки экспорта; при ошибке доступен повтор. Показ результата сам по себе не загружает и не публикует изображение.

Кремовая бумага, экзаменационная типографика и сдержанные Vice-акценты сохранены. Скрытая подготовка игрового города начинается с первого вопроса A по прежним правилам RC3; до окончания B практика остаётся сюрпризом.

## Содержание и баллы

Утверждённый состав нового билета и шкала сохранены: **12 заданий, A — 24, B — 40, C — 36; максимум 100, проходной балл 60**. A показывает правильность сразу и итог после части. B показывает баллы после части, ключ — в финальном разборе. C оценивается на финале.

`contentEdition: 15`, версия локальных сохранений — `4`. В новом задании на хронологию пять игр с логотипами выбираются последовательными нажатиями; баллы остались прежними. Добавлены оригинальные записи опубликованной ветки Netlify, чтобы восстановить её сохранённые ответы по прежним ID и ключам. Старая попытка продолжает свой билет. Для актуального билета начните новую попытку.

Исторические ссылки с одним номером 13/14 неоднозначны между архивной и опубликованной ветками; в RC4 они сохраняют маршрутизацию архивного RC3. Новые ссылки получают номер 15. Точная совместимость и границы описаны в `release-notes/rc4-netlify-compat.md`.

## Развёртывание полного ZIP

1. Распакуйте архив и разместите **всё его содержимое** в корне статического HTTPS-сайта. `index.html`, `assets/`, `native-vc/` и остальные файлы должны лежать рядом.
2. Сохраните пути и имена файлов, включая двоичные части runtime и файлы со знаком `+`. Установка пакетов и сборка не нужны.
3. При необходимости настройте Telegram в `config.js`. Архив сам по себе не обновляет ранее опубликованный сайт.

`botUsername` и `storyUploadEndpoint` в поставке пустые. Сохранение PNG доступно без сервера загрузки; системная отправка файла появляется на поддерживающих её устройствах. Прямой редактор Telegram Stories включается только при поддержке Telegram API и настроенном публичном HTTPS endpoint: он принимает POST с `Content-Type: image/png` и возвращает JSON `{ "url": "https://…" }` с публичным адресом изображения. Загрузка выполняется после нажатия пользователем. Токены бота в клиентскую конфигурацию не помещаются.

## Проверки и ограничения

Полный автоматический прогон RC4: **225/225 PASS**. Проверены баллы и сохранения, подготовка C, жизненный цикл захвата, генерация карточки, конкурирующие обновления и передача готового файла. Автотесты нативного пути используют управляемые адаптеры; они не подтверждают фактическую отрисовку взрыва на GPU или публикацию в мобильном Telegram.

Браузерный проход описывается отдельно в `release-notes/rc4-browser-qa.md`. Успешный запуск настоящего native/GPU и работа Telegram Stories на iOS/Android этим README не заявляются. Готовность города к открытию C по-прежнему зависит от сети, памяти и скорости прохождения теста.

В C сохранены более заметная позиция РПГ и три прохожих из архивного RC3. Это отличается от прежней публикации Netlify; цели и баллы совпадают. Из опубликованной ветки перенесена защита от случайного сворачивания Telegram во время видимой практики. Скрытая подготовка C не блокирует жесты теста.
