# ЕГЭ по истории GTA · RC4.8

Итерация от **18 ноября 2026**. Полный ZIP для локального запуска и Netlify Drop, основан на RC4.7.

## Запустить

Распакуй **весь архив**. Внутри сразу лежат `index.html`, `assets/`, `native-vc/` и файлы запуска.

- macOS: `START-MAC.command`.
- Windows: `START-WINDOWS.cmd`.
- Linux: `sh START-LINUX.sh`.

Нужен установленный Node.js 16+ или Python 3.7+. Оставь окно запуска открытым. Если браузер не открылся сам, скопируй HTTP-адрес из этого окна. `127.0.0.1` работает на том же компьютере, где запущен сервер. `index.html` двойным щелчком не запускает практику.

Для **Netlify Drop** загрузи целиком распакованную папку, в которой непосредственно находится `index.html`. Build command не нужен. Самостоятельная практика — `/rpg/`.

## Что доведено

1. **Один визуальный стиль.** Кремовая бумага, розоватый бланк, клетки, индиго, малиновый и золото. Обложка сохранена; шапка, ответы, радио, переходы, результат и управление C используют одну палитру и одинаковые рамки.
2. **Крупные кнопки.** Основные действия — 56 px; ответы — 58–60 px. Выбор и нажатие видны без скачков размеров. Панель «Дальше» имеет непрозрачную подложку. В машине выход удержанием — 48 px; газ и тормоз остаются раздельными.
3. **Цельная карточка 9:16.** Один настоящий игровой кадр без второй фоновой копии. Сохраняются пропорции и центральная область прицела. Очевидные парные чёрные поля аккуратно обрезаются; тёмная игровая сцена не удаляется.
4. **Характер результата.** Одна короткая фраза зависит от баллов. Например, при A 6/24 + B 9/40 + C 31/36: «Теорию завалил. Практику вывез.» Итог остаётся 46/100, статус — пересдача. Баллы A/B/C и звёзды крупнее.
5. **Сохранение PNG.** Видимая карточка и скачиваемый файл используют один Blob. Для скачивания есть обычная ссылка браузера; файл подготовлен до нажатия.
6. **Меньше повторов.** У задания на хронологию короткий заголовок и одна инструкция. Исторические данные билетов и начисление баллов сохранены.

12 оцениваемых заданий; максимум **100**, зачёт от **60**. A — 24, B — 40, C — 36. Правильность, оценки и звёзды раскрываются после финальной комиссии.

## Практика и ранняя подготовка

Исправления RC4.7 включены целиком: подготовка с обложки, общий кэш и ограниченный резерв памяти, перенос подготовленного города в C, оружие перед игроком, выход четырёх персонажей из вертолёта, вопрос наблюдательности, раздельные руль/газ/тормоз, встречные машины и прохожие.

Код предзагрузки и файлы движка побайтно совпадают с проверенной RC4.7. Первая подготовка зависит от сети, времени в A/B, памяти и доступности WebGL 2. Универсального нулевого ожидания на любом устройстве эта версия не обещает. Если подготовка ещё идёт, показываются реальные этапы, ответы сохраняются.

- **376/376 автоматических проверок**.
- Настоящий A/B-прогон текущего выпуска, включая HESOYAM, обе музыкальные страницы, хронологию и восстановление после обновления страницы.

- В этой удалённой среде отключён WebGL 2. Сам GPU-заезд, поведение камеры, сцена с персонажами и Telegram на физическом телефоне в этой итерации не подтверждены. Макеты C не выдаются за запущенную игру.

Прямой вызов Telegram Stories зависит от настройки HTTPS-выдачи картинки (`storyUploadEndpoint`). При доступном системном шеринге показывается «Поделиться», иначе — сохранение PNG. Эта сборка не добавляет сервер загрузки картинки.
