# ЕГЭ по GTA · RC4.1

17 ноября 2026. Исправления запуска и единый архив для локального теста и статического деплоя.

## Обнаруженная причина 404

На текущем Netlify файлы RC4 опубликованы во вложенной папке `dist`: `/` возвращает 404, а `/dist/index.html` возвращает приложение. Проверены версия RC4 и точное совпадение `app.js` с выданным RC4. Это ошибка уровня публикации, а не повреждение игровых файлов.

У RC4.1 `index.html`, `app.js`, `assets/`, `native-vc/` и файлы запуска находятся непосредственно в корне ZIP. На Netlify публикуется именно эта папка. Правила `_redirects` сохраняют ранее выданные ссылки `/dist/*` после обновления в корень.

## Исправления

- Стартовый экран есть уже в HTML. При недогруженном скрипте или ошибке запуска появляется сообщение и ручная кнопка повтора.
- Ожидание вопросов ограничено 12 секундами с отменой запроса, включая чтение ответа; ожидание стартовых скриптов — 20 секундами.
- Для прямого открытия через `file://` показана инструкция запуска сервера. Сохранённые ответы и имя не очищаются.
- Один пакет работает локально и как корень статического деплоя. Mac-запуск учитывает Homebrew и установленные версии Node; системный Python, способный вызвать установщик Xcode, не запускается.
- При занятом порте выбирается свободный, фактический адрес выводится в окне. Окно с ошибкой не закрывается автоматически.

## Границы проверки
