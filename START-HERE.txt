ЕГЭ ПО GTA · RC4.9
Один архив для локального теста и публикации.

ЛОКАЛЬНО НА КОМПЬЮТЕРЕ
1. Распакуй весь ZIP в обычную папку. index.html и START должны лежать рядом.
2. Открой файл своей системы:
   macOS   — START-MAC.command
   Windows — START-WINDOWS.cmd
   Linux   — START-LINUX.sh, из терминала: sh START-LINUX.sh
3. Браузер откроет экзамен. Окно запуска оставь открытым до конца теста.
   Если браузер не открылся сам, скопируй напечатанный в окне HTTP-адрес.

Нужен установленный Node.js 16+ или Python 3.7+. Запуск выбирает доступный
вариант; ничего не скачивает и не устанавливает. На Mac поиск учитывает
Homebrew, /usr/local и установленные версии nvm. Системный Python macOS
не вызывается, чтобы не запускать установщик Xcode.

Не открывай index.html двойным щелчком: части C нужен HTTP-сервер.
Адрес 127.0.0.1 работает только на том компьютере, где запущен START.
Для остановки сервера нажми Ctrl+C. Если увидишь ошибку, окно останется
открытым — текст ошибки можно скопировать или прислать скриншот.

ПУБЛИКАЦИЯ НА NETLIFY
Распакуй ZIP и перетащи на ручной Deploy всю папку, в которой непосредственно
лежит index.html. В корне публикации должны быть index.html, app.js, assets/
и native-vc/. Не выбирай папку уровнем выше и не загружай один index.html.
Для настройки Publish directory укажи именно эту папку. Build command не нужен.

Для 3D-части C нужен браузер с WebGL 2. Имя и аватар Telegram подгружаются
при запуске внутри Telegram. В обычном браузере имя вводится вручную.

Изменения этой версии и проверка: README-RC4.9.md.
