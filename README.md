# Подготовка к GTA VI

Короткий одиночный выезд по Ocean Drive в Vice City. Встречай гостей на площадке, найди машину и доберись по набережной до финала. Миникарта показывает расстояние до игровой цели. На заезде можно ехать в своём темпе.

## Запуск

Распакуй всю папку. На Mac открой `START-MAC.command`, на Windows — `START-WINDOWS.cmd`. В Linux запусти `sh START-LINUX.sh`. Можно также запустить `node server.cjs` из этой папки. В окне появится точный адрес игры. Для запуска сервера нужен Node.js 16+ или Python 3.7+.

В настольном Safari можно открыть `index.html` напрямую и нажать «Открыть папку игры». Выбери ту же распакованную папку. Браузер прочитает игровые ресурсы с диска.

На статическом HTTPS-хостинге помести `index.html`, корневые скрипты, `assets/` и `native-vc/` рядом. Этот режим подходит для ссылки на телефоне. Нужен WebGL 2.

## Управление

На телефоне ходьба и руль находятся слева. Для наведения потяни по сцене. Газ и тормоз работают отдельно, для выхода из машины удерживай кнопку. На клавиатуре работают WASD, F для посадки и кнопки на экране. Пауза находится справа вверху.

## Для разработки

`native-vc/native.js` связывает готовность движка, игровые события, HUD и переходы. В `scripts/build-city.py` находятся сцены и условия завершения. После их изменения запусти `python3 scripts/build-city.py`. Скрипт пересоберёт `range.scm` и соответствующий `range-config.json`. Движок и ресурсы Ocean Drive лежат в `native-vc/runtime/`.

`native-vc/ride-report.js` собирает сводку и PNG 1080 × 1920. Боезапас считывается из игры, а каждая уничтоженная цель требует подтверждения попадания и уничтожения. Успешная миссия отмечается один раз. Время учитывает активную игру. Для изображения используется кадр текущего выезда. При сбое захвата остаётся сводка с числами.
