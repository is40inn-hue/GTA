# ЕГЭ GTA 0.5.1 · Допуск в GTA VI

**Экспериментальная первая итерация сюжетного апдейта поверх проверенной RC4.9.**

## Что нового

После «Начать экзамен» в актуальном варианте (edition 16) появляется короткая катсцена:

1. Экзаменационный класс в стиле старой GTA: парты, экзаменатор, доска, закат за окном и билет.
2. Экзаменатор: «Телефоны и чит-коды запрещены. Оружие получите на практической части».
3. Камера переходит к билету, после которого **сразу открывается первый вопрос A**.

Есть кнопка **«Пропустить»**; при включённом системном reduced motion сцена занимает около 1,6 секунды вместо 12 секунд. В фоновом/скрытом окне таймер сцены не движется. Возвращение в сохранённый экзамен не запускает катсцену повторно; откроется обычный экран продолжения части A. Старые варианты сохраняют свой прежний вход.

Рисованная 2.5D-сцена — оригинальная стилизация, не оригинальная катсцена Rockstar. Новые файлы сцены лёгкие; дополнительных JS-запросов в загрузке нет.

## Что специально не изменяли

Вся структура A/B/C и вопросы, логика начисления **100 баллов / проходной 60**, сохранение, Telegram-профиль, карточка результата, практика `native-vc/` и её ресурсы, WebGL, прогрев C и отдельный режим `/rpg/` — сохранены из RC4.9.

## Запуск и тест

- **Локально:** распаковать ZIP и запустить `START-MAC.command` или `START-WINDOWS.cmd` / `sh START-LINUX.sh`. Не открывать `index.html` напрямую через `file://`.
- **Netlify Drop:** перетащить содержимое архива с `index.html` в корне сайта. Build command не требуется.
- **Ручной сценарий:** открыть домашний экран → «Начать экзамен» → дождаться перехода A либо нажать «Пропустить» → ответить на первый вопрос → обновить страницу и продолжить сохранённую попытку.

## Проверки и ограничения

- Регрессия: 390/390 RC4.9 автопроверок пройдено на обновлённом коде.
- Новая катсцена: 6/6 отдельных сценарных тестов пройдено (автопереход, отмена, остановка в фоне, reduced motion, fallback и состав сцены).
- Статичный мобильный превью-рендер 390×844 выполнен в Chromium из тех же SVG/CSS.
- Реальный запуск приложения через HTTP в Chromium в этой рабочей среде ограничен политикой доступа к локальному адресу; поэтому полное UI-прохождение в браузере и физический iPhone не заявляются проверенными.
- Публичный деплой **не производился**. Первым делом проверить видимость обложки, переходы, работу мини-игры C на iPhone.
