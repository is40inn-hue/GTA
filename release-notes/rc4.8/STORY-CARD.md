# RC4.8 — финальная карточка

## Изменения

- Одна фотография из практики на всю ширину. Убраны увеличенная подложка, второе изображение, внутренняя видеорамка и искусственные поля композиции.
- Кадр масштабируется с сохранением пропорций. Центральная область прицела остаётся в центре. За пределами этой области края исходного кадра могут обрезаться; это осознанное кадрирование, а не растяжение.
- Общий помощник `GTAImageContentBounds.detect()` удаляет из сохранённых ранее кадров только подтверждённые симметричные чёрные полосы. При отсутствии помощника, ошибке чтения или неверных границах используется исходное изображение. Помощник не вырезает тёмную сцену по предположению.
- Подпись «ПОСЛЕДНИЙ ЗАЛП» появляется только при доступном изображении и метаданных настоящего взрыва в сцене 3. Для других кадров — «КАДР ИЗ ПРАКТИКИ». Без кадра сохраняется честная типографическая карточка.
- Добавлена одна короткая фраза по результатам. Общая функция `GTAStory.resultLine(data)` доступна также для текста шера и доступного описания результата.
- Баллы A/B/C и звёзды увеличены; три колонки имеют одинаковые размеры. Основная рамка изображения — 6 px, внутренние разделители — 2 px.
- Формат 1080 × 1920, точная обложка-источник логотипа, аватар/инициал, имя, порог и общие баллы сохранены.

## Правила фразы

| Условие | Фраза |
| --- | --- |
| Тренировка | Пробный заезд. До встречи на экзамене. |
| Общий результат от 90 | Комиссия просит автограф. |
| Теория ниже 60%, практика от 70% | Теорию завалил. Практику вывез. |
| Теория от 80%, практика ниже 50% | Лор знаю. За руль не пускайте. |
| Остальные зачётные результаты | Экзамен сдан. Ностальгия подтверждена. |
| Остальные результаты ниже порога | Есть что вспомнить. Есть что пересдать. |

Теория — сумма A+B. Противопоставление теории и практики применяется только к полной числовой разбивке с максимумом 100, сумма которой совпадает с показанным округлённым результатом. Отсутствующая или устаревшая разбивка не порождает заявления о конкретных навыках. Фраза не заменяет статус «ЗАЧЁТ» / «ПЕРЕСДАЧА».

## Проверка

- `node --test tests/story-card.test.cjs`: 25 проверок пройдены.
- Проверены границы 60%/70%/80%/50%, общий порог 59/60, 89/90, тренировочный режим, неполные и несовместимые данные.
- Проверены портретный, альбомный и квадратный кадры: ровно одно рисование изображения, заполнение всей области, сохранение пропорций, центральная точка без смещения.
- Проверены прежние чёрные полосы, ошибочный помощник, нечитаемые/небезопасные изображения, длинное имя, отсутствие аватара, отсутствие кадра, корректность звёзд.
- `tests/story-card-preview.cjs` создаёт PNG с явной тестовой сеткой, а не с поддельным игровым скриншотом. Визуально проверены портретный результат 60, альбомный 100, типографический 59; дополнительно подготовлен результат 46 с разбивкой 6/24, 9/40, 31/36.

Это проверка композиции/рендера Canvas 2D. Она не подтверждает прохождение нативной 3D-сцены или публикацию истории на устройстве пользователя.
