# ЕГЭ по истории GTA — RC4.8

**18 ноября 2026 · Asia/Bangkok**

## Итог

Сборка доведена в выбранной эстетике: русский экзаменационный бланк, учебник ЕГЭ и олдовая GTA. Основная работа этой версии — единый интерфейс, цельная финальная карточка и надёжное браузерное сохранение результата. Сценарий и ранняя подготовка города продолжают RC4.7.

### Карточка результата

Ранее один кадр рисовался дважды: затемнённой подложкой и уменьшенной вставкой. Теперь изображение заполняет одну область без искажения пропорций, с центром кадрирования на центральной области прицела.

Общий необязательный модуль распознаёт только очевидные парные чёрные поля. Он работает и с новыми native-кадрами, и со старыми сохранёнными JPEG. В native-потоке используется уже имеющийся пробник 96 px — дополнительного чтения GPU нет. При сомнении или ошибке чтения сохраняется исходный кадр.

Надпись «ПОСЛЕДНИЙ ЗАЛП» появляется только при наличии реального изображения взрыва из C3. Другой реальный кадр подписывается «КАДР ИЗ ПРАКТИКИ». Если изображения нет, используется типографический бланк. Отсутствующая сцена не подменяется нарисованным взрывом.

Примеры фраз:

- При слабой теории и сильной практике: «Теорию завалил. Практику вывез.»
- При сильной теории и слабой практике: «Лор знаю. За руль не пускайте.»
- От 90 баллов: «Комиссия просит автограф.»

Фраза не меняет оценку или статус. На примере 6 + 9 + 31 результат остаётся **46/100, пересдача**. При неполной или противоречивой разбивке используется нейтральный текст.

### Сохранение

Результат сразу отображается одной картинкой 1080×1920. Прямая ссылка скачивает тот же готовый Blob, который виден на странице, с именем `gta-ege-story-<балл>.png`. Не требуется ждать рендера после нажатия. Системный share сохраняет пользовательский жест. Автоматической публикации или отправки результата нет.

## Приоритет S: первый запуск C

Проверена цепочка: первый показ обложки → фоновая подготовка → A/B → прогрев native-сцены → передача того же runtime в C. Код предзагрузки, общий сервис файлов, warmup, управление и SCM побайтно совпадают с исходной RC4.7. Сохранены:

- ранний запуск подготовки без ожидания C;
- отсутствие отмены текущего файла при обычном тапе A/B;
- резерв памяти при недоступном постоянном кэше;
- учёт уже подготовленных байтов при открытии C;
- отсутствие запущенного игрового таймера в скрытой сцене;
- освобождение резерва после первого успешного кадра открытой практики.

В унаследованном тесте реального пакета RC4.7 подготовлены **69 804 226 байт / 464 части**, при передаче в C — **0 дополнительных загрузок**. Это тест локального транспорта с ускоренным планировщиком, не измерение интернета или GPU телефона. В этой версии проверено совпадение 1 062 файлов `native-vc/runtime/` с восстановленным RC4.7; игровой пакет не заменялся.

Нельзя гарантировать отсутствие ожидания при любой сети, ограниченной памяти, экономии трафика или выгрузке WebView системой. Для устройств с известной памятью ≤2 GB и недоступным постоянным кэшем резерв ограничен 16 MiB. Экран ожидания остаётся необходимым и показывает реальные стадии подготовки.

## Сценарий C, сохранённый из RC4.7

Первое оружие появляется перед текущим положением игрока. Парень в белом, Пудж, кубический персонаж и девушка из клуба выходят из одного вертолёта и направляются к игроку. Вопрос по двум гостям появляется после подтверждённого наблюдения, не даёт дополнительных баллов и раскрывается в финале. Парень в белом — адаптированный native-прохожий, не оригинальная модель CJ из San Andreas.

В машине отдельные руль, газ и обычный тормоз/назад, сглаживание руля и выход удержанием. На маршруте две встречные машины и прохожие. В этой версии игровой сценарий, плечи Пуджа, геометрия, управление и оценка не менялись; обновлены только оформление C и обработка кадра для результата.

## Проверка RC4.8

**Автоматические проверки: 376 прошли, 0 ошибок.** Проверены оценка и пороги, совместимость старых билетов, сохранения, предзагрузка, native-протокол, управление, crop, карточка и экспорт. Исправлены две обнаруженные при интеграции вещи: список необязательных модулей запуска и попытка изменить исторические данные вопроса. Короткий заголовок перенесён в слой отображения; старые данные сохранены.

**Браузер:** пройден актуальный выпуск 16: четыре A-вопроса с изображениями, пять B-заданий, обе музыкальные страницы, HESOYAM, порядок пяти обложек. Проверено восстановление после обновления страницы. Баллы и правильность не раскрывались в промежуточных переходах. Основная кнопка — 56 px, поля ответа — 58–60 px на проверенных ширинах 320/390/430.

**3D-ограничение:** удалённый Chrome вернул `C-GPU`, `WebGL 2 unavailable`, `GL_RENDERER = Disabled`. Игра на GPU не исполнялась. Для проверки остатка потока три C-сцены были пропущены через видимые технические кнопки. A/B сохранились, комиссия показала **64/100**, звёзды **5/5/1**. Это проверка отказоустойчивости, не прохождение практики.

**Экспорт:** основная страница браузера подтвердила событие скачивания. Полученный файл проверен как PNG **1080×1920**, **1 635 252 байта**. SHA-256: `04bcc46897829b6c29f6636763e5a964339638b232e4f8cad316c6c39395802e`. Проверка внутри внешней тестовой iframe-рамки не получила события; проверка основной страницы успешна.

**Вёрстка C:** использованы отдельные страницы на реальном HTML/CSS, явно подписанные «Макет интерфейса · движок не запущен». Проверены вопрос, управление и загрузка; на 320×600 и 390×780 элементы помещаются. При 390 px выход и пауза — 48 px, газ — 68 px, тормоз — 60 px. Эти макеты не подтверждают поведение настоящей сцены или Telegram.

## Финальная проверка на телефоне

Остался один реальный прогон внутри Telegram: первое открытие на чистом устройстве → A/B → C → управление и сценка → финальный взрыв → сохранение/системный share. Это проверка возможностей конкретного телефона, первой сети и WebView. Напрямую открыть Telegram Stories можно только при настроенном HTTPS-endpoint для выдачи изображения; без него доступны поддерживаемый системный share и PNG.
