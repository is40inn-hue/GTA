# RC4 и опубликованная native-сцена

База нового ZIP — проверенный архив RC3 от 15.11.2026. Адресная сверка 16.11.2026 с https://incandescent-clafoutis-f22c0a.netlify.app/ показала две отличающиеся native-сцены.

| Файл | Netlify, байт | RC4, байт | Сравнение |
| --- | ---: | ---: | --- |
| range-config.json | 6515 | 6769 | Разные |
| range.scm | 43590 | 44447 | Разные |
| revc.ini | 2641 | 2641 | Полностью совпадают |

Обе пары config → SCM согласованы по записанным размеру и SHA-256. В RC4 сохранена версия из архивного RC3: РПГ расположен у красной метки [249, -1275, 11.5], вместо точки live [249, -1292, 14.5] с подъёмом по пандусу. Конфиг RC4 описывает трёх ambient NPC C1, однократного атакующего actor2, атаку 2200 мс и бегство 3500 мс; scored:false. Live использует другую структуру walker0/walker1/heckler/hecklerUntil. Точное поведение live-бинарника по одному списку переменных не утверждается.

Остальные JSON-настройки целей, боезапаса, баллов, фаз и протокола совпадают. WASM и городской пакет с Netlify не скачивались: их байтовая идентичность не утверждается. В самом RC4 файлы range-config.json, range.scm, revc.ini и игровой runtime не изменены относительно исходного RC3 ZIP. Новый захват кадра работает в JS-wrapper после отрисовки и не переписывает SCM.
