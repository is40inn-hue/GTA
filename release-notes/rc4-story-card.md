# RC4 — готовая карточка результата

## Контракт

Существующий синхронный API сохранён:

```js
const canvas = GTAStory.draw({
  name,
  avatarImage,          // optional decoded Image / ImageBitmap / canvas
  score,
  passScore: 60,
  mode: 'exam',         // 'practice' draws «ТРЕНИРОВКА»
  sections: [
    { points: 24, max: 24 },
    { points: 40, max: 40 },
    { points: 36, max: 36 },
  ],
  highlightImage,       // optional decoded, readable real C frame
  highlight,           // optional capture metadata; not printed on the card
});
```

Возвращается canvas 1080×1920. Renderer не выполняет сетевых запросов, не загружает URL и не управляет публикацией. App должен подготовить изображения, вызвать renderer, экспортировать PNG и использовать один и тот же готовый файл для результата, сохранения и sharing.

Баллы нормализуются в 0–100. Вердикт определяется по `score >= passScore`; противоречивый устаревший `data.passed` не может показать зачёт при 59/100. Для тренировочного режима выводится отдельный статус. На карточке нет варианта, даты, версии, времени ответа, ранга, истории проверки или повторяющихся инструкций.

## Композиция

Кремовая бумага, чернильный синий, приглушённый малиновый, тонкий трёхцветный акцент и небольшая пальма продолжают стиль экзамена. Сверху — название и крупный результат с вердиктом. В центре — реальный снимок C. Снизу — аватар и имя, затем три компактных значения A/B/C.

Основной снимок вписан целиком с сохранением пропорций. Вертикальный кадр не обрезает вертолёт наверху или персонажа внизу. Поля заполняются приглушённой версией этого же снимка. Изображение не дорисовывается, сцену или взрыв renderer не синтезирует. Все значимые подписи расположены между y=140 и y=1740; по краям остаются поля для интерфейса stories.

## Отказы изображений

Каждое переданное изображение сначала проверяется на отдельном canvas 1×1. Не декодированное или запрещающее чтение изображение не попадёт в основной canvas и не сломает его экспорт.

- Без доступной фотографии рисуется инициал имени.
- Без доступного кадра выводится типографическая обложка «ЕГЭ / История GTA / Бланк результатов», без обозначения игрового кадра и без фиктивного взрыва.
- Длинное имя уменьшается только до читаемого минимума, затем сокращается многоточием.
- При отсутствии полной разбивки A/B/C renderer не придумывает баллы за разделы.

## Проверка

Проверены 59/60/100 и противоречивый passed-флаг, тренировочный режим, ограничение чисел, весь исходный portrait/landscape кадр, ошибка/taint у изображения и аватара, длинные кириллические имена, поля stories, отсутствие старых технических строк и отсутствие выдуманной разбивки.

`tests/story-card-preview.cjs` создаёт только внутренние геометрические образцы через @napi-rs/canvas. Исходные образцы подписаны `LAYOUT TEST FIXTURE / NO GAMEPLAY IMAGE`: это сетка, не скрин игры. Превью для 60, 100 и 59 баллов визуально просмотрены. Скрипт и PNG не должны входить в dist. Реальный захват взрыва и Telegram-публикация проверяются отдельно в интеграции приложения.
