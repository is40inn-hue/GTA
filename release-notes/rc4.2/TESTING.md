## Приоритет S: подготовка и открытие C

Проверки исполняют production JavaScript с инертным native port / heap packet:

- обложка без попытки → фоновые байты → скрытый настоящий runtime после готовности байтов;
- Start передаёт временного владельца попытке, не меняя iframe или очередь;
- сохранённая A/B → продолжение, медиаклипы, visibility, BFCache и тихий режим;
- B → та же подготовленная C1: одна main, один iframe, без повторного prepare;
- у storyExam нет трёхсекундного briefing; activate выдаёт одну start-команду;
- если загрузка ещё идёт, текущий runtime продолжает её с приоритетом foreground;
- фоновая ошибка сохраняет A/B и допускает обычный повтор запуска C;
- неактивная страница не запускает задание и не расходует время.

Ограничения: при Save-Data, 2G/3G и устройстве с объявленной памятью ≤ 2 ГБ тяжёлый фоновый прогрев может откладываться. На 3G / малой памяти байты готовятся осторожно. Слабая сеть, отключённый cache или слишком быстрое прохождение A/B могут оставить часть загрузки на вход в C.

## Браузер

В managed preview проверены обложка и отдельная ссылка `rpg/`. Через реальные действия интерфейса пройдены четыре вопроса A, получены 24/24 и 5/5 звёзд. При ширине окна 320 px горизонтального переполнения нет.

В отдельном техническом макете (не включён в ZIP) просмотрены экран ожидания и раскладка управления из production HTML/CSS. Проверена геометрия 320 / 390 / 430 px; в C на 320 и 430 px кнопки оружия 62 px, пауза 48 px, джойстик 122–144 px; элементы не пересекаются. Макет не запускает native двигатель и не является доказательством игровых кадров.

Облачный браузер останавливает реальный native запуск на C-GPU: WebGL 2 context unavailable. Реальное GPU-прохождение, задержка на телефоне, посадка/ротор Maverick и Telegram iOS/Android пока не подтверждены. Mac Finder и Windows launcher в этой Linux-среде не запускались.

## Сохранение совместимости

A/B банк и исторические snapshots сохранены. Максимум 100, зачёт 60, A 24 / B 40 / C 36. Звёзды — только отображение отношения баллов к максимуму; они не меняют оценку или native credit. Старые BUILD/README относятся к своим историческим версиям; актуальный файл — BUILD-RC4.2.json.

## Воспроизводимость

Для запуска tests нужно расположить содержимое ZIP в папке `dist/`, скопировать соседние здесь `tests/` в корень проекта, `scripts/` — туда же. Из корня: `node --test tests/*.test.cjs`. Сам сайт не требует npm install, сборщика или запуска тестов.
